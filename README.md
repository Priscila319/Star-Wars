# 🌌 Projeto Star Wars - API Integration

Este projeto é uma aplicação web simples que consome a [SWAPI (Star Wars API)](https://swapi.dev/) para exibir informações sobre os personagens da icônica franquia Star Wars. O objetivo principal foi praticar o consumo de APIs REST e manipulação do DOM de forma assíncrona.

## 🚀 Funcionalidades

- Busca de personagens aleatórios ou específicos da franquia.
- Exibição dinâmica de dados (Nome, Altura, Peso, etc.).
- Interface responsiva com foco na experiência do usuário.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura da página.
- **CSS3**: Estilização, incluindo o uso de `border-radius` para botões e layouts responsivos.
- **JavaScript (ES6+)**: Lógica de programação, consumo de API com `fetch` e funções `async/await`.
- **Git & GitHub**: Versionamento de código e gerenciamento de conflitos.
